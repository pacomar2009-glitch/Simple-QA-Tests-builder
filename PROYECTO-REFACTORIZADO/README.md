## ⚡ Inicio Rápido

```bash
# 1. Instalar dependencias
cd extension && npm install
cd ../gemini-mcp-server && npm install

# 2. Ejecutar tests
cd ../extension && npm test

# 3. Construir extensión
npm run build
```
